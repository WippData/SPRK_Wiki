# Product Glossary

Use this glossary to translate common SPRK labels into plain language and find the guide where each label matters.

## Quick reference

| Term or Item | Meaning | Where It Matters |
|---|---|---|
| `Active company` | The company currently selected in the sidebar and used by the rest of the app until you switch again. | [Switch between companies](../company-setup-and-migration/switch-between-companies.md) |
| `Backups` | The settings area for automatic backup timing, backup location, manual backup runs, and company-file controls. | [Review backup settings visible in the product](../backups-and-data-safety/review-backup-settings-visible-in-the-product.md) |
| `Checklists` | Repeatable operational task lists used to track accounting or close-style work without posting transactions by themselves. | [Use checklists](../checklists-and-period-end-work/use-checklists.md) |
| `Chart of Accounts` | The list of accounts you classify transactions to and report from. | [Understand the chart of accounts structure](../ledger-and-chart-of-accounts/understand-the-chart-of-accounts-structure.md) |
| `Company file` | A company-scoped export or import package used to move one SPRK company without moving every company in the local database. | [Export and import company files](../backups-and-data-safety/export-and-import-company-files.md) |
| `Categorized` | A bank transaction state showing that its account, party, and other review details have been assigned. | [Categorize and confirm bank transactions](../banking-and-cash-management/classify-bank-transactions.md) |
| `Cleared` | A transaction selected as appearing on the bank or credit-card statement being reconciled. | [Finish a reconciliation](../reconciliation/finish-a-reconciliation.md) |
| `Confirmed` | A bank transaction state showing that review is complete and the accounting entry has been created or linked. | [Choose a banking task](../banking-and-cash-management/review-and-classify-bank-transactions.md) |
| `Control account` | An account reserved for source workflows such as invoices, bills, or payments instead of routine manual posting. | [Understand the chart of accounts structure](../ledger-and-chart-of-accounts/understand-the-chart-of-accounts-structure.md) |
| `Dashboard` | The top-level summary view for recent business activity and quick navigation. | [Understand the dashboard overview](../dashboard-and-navigation/understand-the-dashboard-overview.md) |
| `Draft` | A saved invoice, bill, or check that has not been posted. | [Choose an invoice task](../sales-and-receivables/create-and-open-invoices.md) |
| `Difference` | The amount still left between the cleared activity in SPRK and the statement ending balance. A reconciliation is ready to finish when the difference is zero. | [Finish a reconciliation](../reconciliation/finish-a-reconciliation.md) |
| `Deposit to` | The account that receives a customer payment, such as a bank account or undeposited-funds account. | [Receive invoice payments](../sales-and-receivables/receive-invoice-payments.md) |
| `Grid Edit` | A list-page mode for updating several supported records in a table. | [Use Grid Edit for bulk record maintenance](../dashboard-and-navigation/use-grid-edit-for-bulk-record-maintenance.md) |
| `How To Guides` | Built-in support topics shown from the `Support` tab. | [Use the Support tab](../support-and-troubleshooting/use-the-support-tab.md) |
| `Import preview` | The review step where SPRK shows parsed rows, warnings, and selectable records before an import is confirmed. | [Import bank transactions](../banking-and-cash-management/import-bank-transactions.md) |
| `License` | The settings area for saved license details, purchase access, and workspace-wide usage visibility. | [View license information](../licensing/view-license-information.md) |
| `Matched` | A bank transaction linked to an existing SPRK transaction so the same money movement is not entered twice. | [Match bank transactions](../banking-and-cash-management/match-bank-transactions.md) |
| `Open` | A document state for active receivable or payable work that still needs payment, review, or follow-up. | [Create and open invoices](../sales-and-receivables/create-and-open-invoices.md) |
| `Paid` | A document state showing that the invoice or bill balance has been settled. | [Receive invoice payments](../sales-and-receivables/receive-invoice-payments.md) |
| `Pending` | A review state for bank activity that has been imported or entered but not yet confirmed. | [Review and classify bank transactions](../banking-and-cash-management/review-and-classify-bank-transactions.md) |
| `Pay from` | The account used when a bill is opened or paid. An Accounts Payable control account keeps the bill open; a bank, cash, or credit-card account records a paid-now bill. | [Create a bill](../expenses-and-payables/create-bills.md) |
| `Posted` | Accounting activity that has been saved into ledger or source-document history. | [Record journal entries](../ledger-and-chart-of-accounts/record-journal-entries.md) |
| `Preferences` | Personal and device-level settings such as appearance, formatting, update preferences, and sidebar customization. | [Use the Preferences tab](../preferences-and-personalization/use-the-preferences-tab.md) |
| `Reconcile` | The area used to match account activity to a statement balance and track cleared or unmatched items. | [Start a reconciliation](../reconciliation/start-a-reconciliation.md) |
| `Receive to` | The account used when an invoice is opened or paid. An Accounts Receivable control account keeps the invoice open; a bank or cash account records a paid-now invoice. | [Create an invoice](../sales-and-receivables/create-invoices.md) |
| `Rules` | Saved bank-transaction classification logic used from banking workflows. | [Create and manage rules](../banking-and-cash-management/create-and-manage-rules.md) |
| `Support Activity Log` | The current-session troubleshooting log you can download or clear from the `Support` tab. | [Collect the right details before contacting support](../support-and-troubleshooting/collect-the-right-details-before-contacting-support.md) |
| `Tenant Stats` | The visible `License` table for workspace-wide usage counts. | [Understand usage limits and prompts](../licensing/understand-usage-limits-and-prompts.md) |
| `Void` | A preserved record state that offsets or cancels eligible activity without treating the original record as if it never existed. | [Understand invoice general ledger impact](../sales-and-receivables/understand-invoice-general-ledger-impact.md) |

## Details

- Use the linked guide when you need to act on a term rather than define it.
- `Active company` describes the company currently selected for day-to-day work. `Tenant Stats` and `License` describe workspace-level information.
- Document states such as `Draft`, `Open`, `Paid`, and `Void` matter because they affect which actions are available next.
- The `Support Activity Log` is for troubleshooting context. It is separate from accounting reports and audit-sensitive transaction history.
- This glossary focuses on SPRK labels and common record states, not every accounting term used outside SPRK.
