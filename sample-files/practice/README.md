# Practice Files

These files are for training and guided practice. They use fictional examples and may intentionally include issues that a guide asks you to find.

## Before you use a file

- Open the related guide first. The guide explains what the file demonstrates and which import or review page to use.
- Work in a demo or practice company unless the guide says otherwise.
- Review every preview, warning, and total before confirming an import.
- Do not treat a practice file as a template for live client data.

## How to download a file

Open the file from its related guide, then use your browser's download control. Keep the original file so you can repeat the exercise if needed.

Practice files are intentionally not shown as a help topic or included in search results. Customers reach them from the guide that explains the exercise.
