# SPRK Practice Sample Files

These files are optional practice assets for public wiki examples. Use them only
when a workflow page links to them and the file type matches the SPRK import or
review surface you are using.

`Import practice file` means the file is intended for an SPRK upload or import
workflow. `Practice reference` means the file supports a review example, but is
not necessarily uploaded directly.
