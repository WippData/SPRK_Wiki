## What to know first

Plugins are optional additions managed by an administrator. A plugin can add pages or reports when it is compatible with your version of SPRK.

Only install plugin bundles from sources your firm trusts. If SPRK shows a warning while previewing a plugin, stop and review it before continuing.

Installed does not always mean visible. Check the plugin card to see whether it is enabled for the current company and available in your version of SPRK.

Accounting work created with a plugin still follows SPRK's normal permissions, review, posting, history, and correction rules.
